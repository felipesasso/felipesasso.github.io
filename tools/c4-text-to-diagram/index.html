C4 Text-to-Diagram

Describe a system the way the C4 model sees it — people, software systems, containers, components and the relationships between them — in a small text format, and watch the diagram render as you type. No drag-and-drop, no hunting for the right shape: just write, and the layout takes care of itself.

Syntax cheat sheet

Each line declares an element or a relationship. Names, technologies and descriptions go in quotes; ids are bare words used to wire relationships together.

title "Some System — System Context"

person User "User" "Description"
person_ext  <id> "Name" "Description"   (person outside your organization)
system <id> "Name" "Description"        (a software system you're modelling)
system_ext <id> "Name" "Description"    (a system outside your organization)

container <id> "Name" "Technology" "Description"
component <id> "Name" "Technology" "Description"
   — add _ext to either for things you don't own (e.g. container_ext)

boundary "Name" {
  ...elements grouped inside this system/container...
}

<idA> -> <idB> "Label" "Technology"     (technology is optional)

# and // start a comment

Switch levels by changing what you declare: people and systems make a System Context diagram; wrap containers in a boundary for a Container diagram; nest component elements inside a container's boundary for a Component diagram.

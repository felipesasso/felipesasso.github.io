Git Workflow Map

Git can feel like four separate copies of your project that you keep nudging code between: the files on your disk, a "draft" of your next save, your local history, and a copy on GitHub. This map shows those four places and the commands that move code between them. Click any box or pill below to see what it does.

How to read it — ↓ commands move your changes "deeper" (toward GitHub), ↑ commands undo or pull things back. Every box and pill is clickable.

Working in parallel

Branches

A branch is just a movable label pointing at a commit. The default branch (often called main) is your project's mainline. Creating a new branch lets you work on something — a feature, a fix — without touching main until it's ready, then merge it back in.

Token Bucket Rate Limiter Simulator

A rate limiter caps how many requests a client can make in a given window, protecting an API from abuse and overload. The token bucket is the algorithm behind most real-world limiters (AWS, Stripe, GitHub): a bucket holds a capped number of tokens, refills at a fixed rate, and every request spends one token — once the bucket is empty, requests get rejected with 429 Too Many Requests until it refills. Tune capacity, refill rate and burst size below, then fire single requests or a burst and watch the bucket drain and refill in real time.

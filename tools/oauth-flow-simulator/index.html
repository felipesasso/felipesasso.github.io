OAuth 2.0 Flow Simulator

A visual state machine for the three classic OAuth 2.0 flows — Authorization Code, Implicit and Client Credentials. Click through the steps (or click any arrow in the diagram) to see exactly what travels over the wire: the redirect URIs, the authorization codes and the tokens themselves.

How to read it — each column is a participant, each arrow is one hop in the flow. Solid arrows have already happened, the highlighted one is where you are now, and dashed arrows are still to come. Use the buttons, the arrow keys, or click any step directly.
